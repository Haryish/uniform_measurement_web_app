🧩 Generate additional patterns

Start with an approved pattern workbook and create even-number variants. Existing patterns are retained.

Rules built in

  • Reads pattern sheets by the Pattern heading.
  • Detects Boys/Girls and class from the sheet name.
  • Detects student rows and measurement columns from the school template.
  • Only writes measurement values into blank cells unless overwrite is enabled.
  • Converts odd numeric measurements to the next even value and rejects 0 / 3-digit values.
  • Keeps the uploaded template's formatting, merged cells, headings and student information.
